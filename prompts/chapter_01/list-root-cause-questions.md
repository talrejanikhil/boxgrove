# List Root Cause Questions

For every row marked questionable, wrong, or cannot tell, list the
questions we would ask to find the cause, such as which intent was
chosen, what a tool returned, or which step was slow. For each question,
say whether we can answer it today from the CSV and the application's
console output, and what we would have to add to answer it. Finish with a
short list of the things we cannot see at all.
